# Models

This directory is used for model checkpoints saved during training and experiment runs.

Training scripts write `.pth` files here automatically. The exact output path is usually defined either in a YAML config file or generated by `src/run_experiments.py` from the selected results CSV, dataset, strategy, hyperparameters and seed.

Example checkpoint path:

```text
models/final_active_best/octmnist/octmnist-final_active_best-egl_fc-init3p-batch3pb-epc5-budget30p-17.pth
```

Model files are relatively large. A single ResNet18 checkpoint is about 45 MB, so generated checkpoints are ignored by Git by default.

## Versioned Example

The repository includes one representative checkpoint:

```text
models/final_active_best/octmnist/octmnist-final_active_best-egl_fc-init3p-batch3pb-epc5-budget30p-17.pth
```

This file is kept as an example of a real trained model artifact. The remaining generated checkpoints are intentionally left untracked to avoid storing all experiment outputs in the repository.
