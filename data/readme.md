# Data Directory

This folder contains the datasets used in the experiments.

## Important Note
Due to file size limitations, only **pneumoniamnist** is stored in git. To run the experiments with other datasets, you must download the missing files manually.

## Dataset Sources
All supported datasets are part of the MedMNIST collection hosted on [Zenodo](https://zenodo.org/records/10519652).

| Dataset | Repository Status | Direct Download Link |
| :--- | :---: | :--- |
| **PneumoniaMNIST** | ✅ Included | [Download](https://zenodo.org/records/10519652/files/pneumoniamnist.npz?download=1) |
| **BloodMNIST** | 📥 Missing | [Download](https://zenodo.org/records/10519652/files/bloodmnist.npz?download=1) |
| **OCTMNIST** | 📥 Missing | [Download](https://zenodo.org/records/10519652/files/octmnist.npz?download=1) |
| **PathMNIST** | 📥 Missing | [Download](https://zenodo.org/records/10519652/files/pathmnist.npz?download=1) |

## ⚙️ Setup
1. Download the missing `.npz` files from the links provided above.
2. Extract the `.npz` files directly into this `/data/` directory.
3. Ensure the filenames remain unchanged (e.g., `bloodmnist`).
